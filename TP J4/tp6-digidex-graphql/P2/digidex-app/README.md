# digidex-app (TP6 P2)

Client Angular + Apollo pour explorer les Digimon depuis le serveur GraphQL local.

## Fonctionnalites
- Liste de Digimon avec recherche et pagination.
- Detail d'un Digimon via route dynamique.
- Favoris (signals, etat partage).

## Prerequis
- Le serveur GraphQL `P1/digidex-api` doit tourner sur `http://localhost:4000`.

## Commandes
```bash
npm install
npm start
npm run build
```

## URL
- Front: `http://localhost:4200`
