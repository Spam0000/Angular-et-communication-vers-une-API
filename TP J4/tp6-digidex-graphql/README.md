# TP6 DigiDex GraphQL

Projet full-stack decoupe en deux parties pedagogiques.

## Arborescence
- `P1/digidex-api/` : API GraphQL (Apollo Server).
- `P2/digidex-app/` : client Angular consommant l'API GraphQL.

## Demarrage rapide
1. Lancer le serveur:
```bash
cd P1/digidex-api
npm install
npm start
```
2. Lancer le client:
```bash
cd P2/digidex-app
npm install
npm start
```

## URLs
- GraphQL : `http://localhost:4000`
- Angular : `http://localhost:4200`
