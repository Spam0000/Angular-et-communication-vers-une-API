# pokedex (TP J2)

Application Angular Pokedex avec architecture moderne.

## Fonctionnalites
- Liste des 151 premiers Pokemon.
- Recherche instantanee.
- Fiche detail (`/pokemon/:name`).
- Favoris via service + signals.

## Commandes
```bash
npm install
npm start
npm run build
```

## URL
- Front: `http://localhost:4200`
