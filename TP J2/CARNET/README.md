# TP J2 - Carnet de contacts (CRUD)

Ce dossier contient le TP CRUD Angular avec json-server.

## Contenu
- `carnet-app/` : application Angular.

## API locale
Un `db.json` est place dans ce dossier pour json-server.

```bash
npx json-server db.json
```

## Lancer le front
```bash
cd carnet-app
npm install
npm start
```
