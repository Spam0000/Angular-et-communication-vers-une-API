# carnet-app (TP J2 CRUD)

Application Angular CRUD pour gerer un carnet de contacts.

## Fonctionnalites
- GET: lister les contacts.
- POST: ajouter un contact.
- PUT: modifier un contact.
- DELETE: supprimer un contact.
- Etats loading/error.

## Prerequis
- API locale json-server sur `http://localhost:3000/contacts`.

## Commandes
```bash
npm install
npm start
npm run build
```
